STORY TO SONG - WEBSITE PACKAGE

Files:
- index.html : main website
- styles.css : design and mobile layout
- script.js  : smooth scrolling

HOW TO PREVIEW:
Open index.html in a web browser.

HOW TO PUBLISH:
Upload the contents of this folder to your web host (for example Vercel, Netlify, or similar static hosting).

CURRENT FORM BEHAVIOR:
The order form uses a mailto form addressed to story2songstudio@gmail.com. When a customer submits, their device's email app opens with the form data. This avoids needing a database on the starter version.

BEFORE TAKING PAID ORDERS:
Add a proper hosted form/database and payment checkout (such as Stripe) so orders are captured reliably even if the customer does not have a configured email app.
